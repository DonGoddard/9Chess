# 9 Chess

**[Play it in your browser →](https://dongoddard.github.io/9Chess/)**

Chess as a luxury object: pieces in marble, gold, crystal and rare woods, boards to match, and
somewhere worth playing — a grand hall, a lakeside dock, a park table, a tournament floor.

- Play online, or practise against Stockfish at five named strengths
- 185 puzzles, and a guide for anyone learning the game
- A 3D board with a flat 2D board beside it, or tucked into a corner

This repository holds only the built game. The engine for the practice opponents is
[Stockfish](https://stockfishchess.org), used unmodified under the GPL v3 — its licence and a link
to its source ship with the build in `TemplateData/sf/`.
